# Architectural decision records

Accepted decisions for Turpinverse data, consumers, and tooling. Newest numbered ADRs are not necessarily last in the list; use status and `supersedes` / `superseded_by` in front matter.

## Adding an ADR

1. Use the next `adr-NNNN-[title-slug].md` sequence (four digits).
2. Follow [`.agents/skills/create-architectural-decision-record/SKILL.md`](../.agents/skills/create-architectural-decision-record/SKILL.md).
3. Start as **Proposed** unless the change is already shipped; set **Accepted** when merged.
